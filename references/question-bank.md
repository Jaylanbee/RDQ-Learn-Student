# RDQ-Learn-Student 題庫｜科目起始問句 × 迷思概念

> 本檔供 `SKILL.md` Phase 3 使用。Phase 0 判定科目後，讀取對應科目的起始問句。每題包含 L1 蘇式問句與 L2 降級選項。所有題目鎖定教材範圍，不超綱。
>
> 這是**活文件**：教學現場問出效果好的題目請回填。

## 數學

適用：數與量、代數、幾何、函數、統計與機率。

### Ⅲ 挖掘題

| L1 問問看 | L2 選一個 | 不問會怎樣 |
|---|---|---|
| 這個公式是為了解決什麼問題出現的？——生活中什麼時候會用到它？ | A) 知道生活例子也能說公式  B) 記得公式但不知道什麼時候用  C) 兩個都不太確定 | 只背公式不知道用途，題目換包裝就認不出來 |
| 這個題目你第一步為什麼要這樣做？ | A) 能清楚說出解題思路  B) 知道要這樣做但說不出為什麼  C) 連第一步也不確定 | 看不懂解題邏輯，只能照抄步驟，換數字就不會算 |
| 這題有沒有其他算法？——你學過的方法之外還有嗎？ | A) 知道至少兩種算法  B) 知道有但想不起來另一種  C) 只會一種 | 只會一種方法卡住就整題放棄 |
| 這個圖形／式子最關鍵的特徵是什麼？——一眼看過去最先注意到什麼？ | A) 能說出關鍵特徵（開口方向／斜率／對稱軸）  B) 大概知道但要指一下才知道  C) 看不出來 | 不會抓關鍵特徵，看到圖形題就亂猜 |

### Ⅳ 盲點提示

- 你有想過為什麼這個公式長這個樣子嗎？——不是背它，是看它怎麼來的。
- 這題如果數字很大或很醜，你的做法會不一樣嗎？
- 你確定你記的公式沒有漏掉負號或平方？——檢查一下你最常錯的那種題型。

### 常見數學迷思

| 迷思 | 正確觀念 | 為什麼會搞錯 |
|---|---|---|
| (a+b)² = a² + b² | (a+b)² = a² + 2ab + b² | 分配律只記得平方給 a 和 b，忘了交叉項 |
| 負負得正只適用乘法 | 負負得正是乘法規則，加減法不是 | 把規則套錯地方 |
| 分數加減直接加減分子分母 | 要先通分再加減分子 | 把分數加減跟分數乘法定義搞混 |

## 自然

適用：生物、理化、地科。

### Ⅲ 挖掘題

| L1 問問看 | L2 選一個 | 不問會怎樣 |
|---|---|---|
| 這個現象你在生活中有沒有看過？——哪裡看過？ | A) 能舉出生活例子也能解釋  B) 有印象但講不清楚  C) 沒想過生活中有 | 學的跟生活脫節，考試換情境就不知道在問什麼 |
| 這個實驗／現象的結果，如果改變一個條件會怎樣？——哪個條件最關鍵？ | A) 知道關鍵條件也知道結果會怎麼變  B) 知道條件改變有影響但不確定怎麼變  C) 沒想過可以改變條件 | 不懂變因操控，實驗題直接送分 |
| 課本說的這個「原因」跟「結果」之間，你覺得中間發生了什麼？ | A) 能說出因果關係的過程  B) 大概知道但中間跳過幾步  C) 只記得結論不記得原因 | 只背結論不記過程，題目反過來問就卡住 |
| 這個構造／名詞的功能是什麼？——它是用來做什麼的？ | A) 能說出功能跟為什麼需要它  B) 知道功能但不知道為什麼需要  C) 只記得名字不記得功能 | 記名詞不記功能，選擇題換個問法就不會 |

### Ⅳ 盲點提示

- 你有想過課本說「通常」或「一般來說」——那代表什麼時候不成立？
- 這個實驗如果在家裡做，你覺得哪一步最容易失敗？
- 你學的這個是「分類」還是「因果」？——有些東西只是讓人好分類，不一定是真正的因果關係。

### 常見自然迷思

| 迷思 | 正確觀念 | 為什麼會搞錯 |
|---|---|---|
| 植物只吸收二氧化碳 | 植物也進行呼吸作用放出二氧化碳 | 只記光合作用，忘記呼吸作用同時進行 |
| 重量＝質量 | 質量是物質多少，重量是重力大小（月球上重量不同） | 生活用語混用 |
| 物體要受力才會動 | 物體不受力時會保持等速運動（慣性） | 日常經驗：推東西才會動，以為力是運動的原因 |

## 國文

適用：課文理解、注音國字、成語、修辭、閱讀測驗。

### Ⅲ 挖掘題

| L1 問問看 | L2 選一個 | 不問會怎樣 |
|---|---|---|
| 這句課文如果用你自己的話說，你會怎麼說？ | A) 能用自己的話流暢翻譯  B) 大概知道意思但講得卡卡  C) 不太確定它在說什麼 | 能換句話說才是真懂，不然只是會背 |
| 作者為什麼要這樣寫？——他寫這段是想表達什麼？ | A) 能說出作者用意或心境  B) 有感覺但說不太清楚  C) 沒想過作者為什麼這樣寫 | 閱讀測驗考作者觀點時直接猜 |
| 這課課文跟你生活中有沒有關係？——哪個地方讓你有感覺？ | A) 能連結到自己的生活經驗  B) 可以想像但沒有真實經驗  C) 覺得古文／課文離生活很遠 | 無法共感就無法深入理解，只能死背翻譯 |
| 這個成語／修辭如果用一句白話文來解釋，是什麼意思？ | A) 能說出成語意義跟使用時機  B) 知道大概意思但不太會用  C) 只背過解釋但現在忘了 | 成語不會用等於沒學，寫作也寫不出來 |

### Ⅳ 盲點提示

- 你有想過這一課如果換成現代作家來寫，他會怎麼寫嗎？
- 作者寫這篇文章的時候心情如何？——你從課文哪一個字看出來的？
- 這個成語有沒有意思相近的另外一個成語？——兩個差在哪？

### 常見國文迷思

| 迷思 | 正確觀念 | 為什麼會搞錯 |
|---|---|---|
| 「幾乎」是程度副詞不是副詞 | 幾乎是副詞沒錯 | 被誤導或老師強調時聽錯 |
| 「的」跟「得」可以互換 | 的（形容詞後）、得（副詞後/動詞後） | 口語發音相同 |
| 所有「之」都等於「的」 | 之可以當代名詞、動詞、助詞，不全是「的」 | 最常見用法是「的」但其他用法被忽略 |

## 英文

適用：單字、文法、句型、閱讀、聽力。

### Ⅲ 挖掘題

| L1 問問看 | L2 選一個 | 不問會怎樣 |
|---|---|---|
| 這個單字你是在課本的哪一課／哪個句子裡學到的？ | A) 記得在哪學過也記得意思  B) 記得看過但忘記在哪裡  C) 完全沒印象 | 單字沒有情境錨點，背了就忘 |
| 這個文法句型，你能不能用它造一個跟課本不同的句子？ | A) 能造出新句子  B) 可以改課本句子但自己造有點卡  C) 只記得課本例句 | 只會照抄沒有內化，寫作題寫不出來 |
| 這個單字的拼法，你最不確定的是哪個字母？ | A) 能完全正確拼出  B) 知道大概但不確定某幾個字母  C) 拼不太出來 | 拼寫錯誤是最常見的扣分原因，而且自己檢查不出來 |
| 過去式／三單動詞為什麼要加這個變化？——你覺得規則是什麼？ | A) 能說出規則跟例外  B) 記得大部分規則但忘了例外  C) 只會背變化表 | 不懂規則只能靠死記，變化一多就混 |

### Ⅳ 盲點提示

- 這個句子如果改成問句，哪裡要變？——不只加問號而已。
- 你確定這個單字是名詞還是動詞？——同一個字可以當兩種詞性。
- 這個文法在口語跟寫作用的時候有不一樣嗎？——有些文法寫作要寫但講話可以省略。

### 常見英文迷思

| 迷思 | 正確觀念 | 為什麼會搞錯 |
|---|---|---|
| like 後面全部接 V-ing | like + to V / V-ing 都可以，意思不同 | 初學只教 + V-ing 簡化版本 |
| 所有名詞複數都加 s | 不規則變化（child→children, foot→feet） | 規則記太熟忘了有例外 |
| is/am/are = 是 | be 動詞也可以當「在」（He is at home） | 初學只學了「是」的用法 |

## 社會

適用：歷史、地理、公民。

### Ⅲ 挖掘題

| L1 問問看 | L2 選一個 | 不問會怎樣 |
|---|---|---|
| 這個事件發生的主要原因你覺得是什麼？——課本說了幾個原因？ | A) 能說出兩個以上原因  B) 記得一個原因但不確定還有沒有別的  C) 只記得發生什麼事不記得原因 | 不懂因果關係，歷史題只能靠背年代硬記 |
| 這個地方／國家在地圖上的哪裡？——附近有什麼明顯的地理特徵？ | A) 能說出位置跟相關特徵  B) 大概知道方位但不確定  C) 只看過文字沒看過地圖 | 地理沒有空間感，考地圖題直接卡住 |
| 你覺得這個政策／制度對當時的人有什麼影響？——誰受益？誰受損？ | A) 能說出對不同族群的影響  B) 知道有影響但不確定具體內容  C) 沒想過政策的影響是什麼 | 學制度只背名字不管影響，題目考「影響」就答不出來 |
| 這三個事件之間有沒有先後順序或因果關係？——哪個先哪個後？ | A) 能排出正確順序也說出原因  B) 可以排出順序但不確定為什麼  C) 看成獨立事件沒有連結 | 歷史事件看不懂連貫性，題目考比較時無法判斷 |

### Ⅳ 盲點提示

- 你有想過，如果你是當時的人，你會不會做一樣的決定？
- 課本說「因為 A 所以 B」——你覺得有沒有可能是因為 C 或 D 也有影響？
- 這個地名／國名你只是在課本上看過，還是知道它在哪裡？——去翻一下地圖。

### 常見社會迷思

| 迷思 | 正確觀念 | 為什麼會搞錯 |
|---|---|---|
| 歷史就是背年代 | 歷史是理解因果跟改變，不是被年代 | 老師或參考書太強調年代記憶 |
| 經度緯度分不清 | 經度南北畫、緯度東西畫 | 名詞太像且課本常一起教沒區分清楚 |
| 權利跟義務一樣 | 權利是你可以做什麼，義務是你必須做什麼 | 教公民時兩個詞常一起出現，學生混為一談 |

## 通用

科目不明確或跨科目時使用。

### Ⅲ 挖掘題

| L1 問問看 | L2 選一個 | 不問會怎樣 |
|---|---|---|
| 你用一句話說你剛剛學了什麼？——不用很完整，一句就好 | A) 能一句話說出重點  B) 要講兩三句才能說清楚  C) 不太知道怎麼濃縮 | 無法總結＝還沒真的搞懂 |
| 你覺得最難的地方在哪裡？ | A) 能說出卡住的地方  B) 知道卡卡但說不出具體哪裡  C) 覺得都不難或不確定 | 不知道自己弱點在哪，複習沒有方向 |
| 你覺得這個跟之前學的哪個東西有點像？ | A) 想到一個連結  B) 覺得有關但說不清楚  C) 覺得完全不同 | 沒有連結的知識容易忘 |

### Ⅳ 盲點提示

- 你確定你懂的這個地方，有沒有可能是你記錯了？——找一個例題驗證一下。
- 你覺得老師如果考這題，會怎麼改數字或條件？
- 你有沒有把課本的練習題遮住答案自己做一遍？
