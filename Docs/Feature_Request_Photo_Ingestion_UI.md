# 聯絡事項：致 RDQ 開發團隊 (功能需求與改進建議)

**主旨：RDQ Web 儀表板 `➕ 匯入外部錯題` 彈窗新增「📷 拍照/圖片上傳與 OCR 辨識」功能建議**

**發信人**：Antigravity Agent 運行框架團隊 (代表家長與學生反饋)  
**收信人**：RDQ 系統總架構師 & 開發團隊  
**日期**：2026 年 8 月 2 日  

---

致 RDQ 系統總架構師與開發團隊：

在實際使用者測試與家長反饋中，我們發現了 Web 儀表板 (`dashboard.html`) 一項非常關鍵的用戶體驗需求：

### 🎯 需求說明與痛點

1. **現狀**：目前 Web 儀表板上的 `➕ 匯入外部錯題` 彈窗僅支援手動文字貼上（文字框：科目、題目內容、答案解析）。
2. **家長與孩子痛點**：國中生手邊有大量實體考卷與小考單，要孩子或家長手動打字輸入題目極為耗時，會大幅降低使用意願。
3. **建議功能**：
   - 請求在 Web 端 `➕ 匯入外部錯題` 彈窗中，**新增「📷 上傳考卷照片 / 拖曳圖片」區域**。
   - 支援點擊選擇圖片或拍照上傳後，發送至後端 API 端點 (`POST /api/ingest`) 自動進行圖片 OCR 解析與題目萃取，實現「拍照即完成錯題防禦卡生成」的極致體驗！

---

### 🛠️ 建議 Web UI 欄位設計

```
+-------------------------------------------------------------+
| ➕ 匯入外部錯題                                              |
|                                                             |
| 科目 / 章節 (選填): [ 例如：自然 - 光合作用 ]                 |
|                                                             |
| 📷 考卷照片上傳 (點擊選擇照片或拖曳圖片至此):                    |
| +---------------------------------------------------------+ |
| |  [📷 點擊上傳 / 拍照照片]  或將考卷照片拖曳至此處         | |
| +---------------------------------------------------------+ |
|                                                             |
| 題目內容 (或由照片自動 OCR 解析):                            |
| [ 請貼上題目內容...                                       ] |
|                                                             |
| 答案解析 (選填):                                            |
| [ 請貼上解答或關鍵字...                                   ] |
|                                                             |
|                          [ 取消 ]  [ 確定匯入 (含照片解析) ] |
+-------------------------------------------------------------+
```

Antigravity 團隊已先於前端 UI 預留圖片上傳介面樣式，靜候貴團隊在後端 API 完成多模態 OCR 解析端點之接軌！
