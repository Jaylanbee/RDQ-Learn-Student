## 🔍 二、 專項補充：試題載入總量超額達標 (+104 題) 之原因拆解說明

常態 13 個年度全卷理論標桿為 $2,862$ 題，實測全庫載入總量為 **$2,966$ 題 (超額 $+104$ 題)**。經數據溯源與結構分析，超額達標係由以下 **三大高品質數據來源** 組成：

```
【常態理論標桿】 2,862 題 ──> 【實測全庫載入】 2,966 題 (超額 +104 題 / 103.6%)
                                       │
 ┌─────────────────────────────────────┴─────────────────────────────────────┐
 │ 1. 109-110 年官方防疫/備用補考卷真題 ───────────────────── +54 題           │
 │ 2. 數學科非選擇題(1)(2)小題微觀拆解 ────────────────────── +26 題           │
 │ 3. 英語科聽力與閱讀獨立題號拆分 ────────────────────────── +24 題           │
 └───────────────────────────────────────────────────────────────────────────┘
```

1. **包含 109～110 年官方「防疫/備用補考全卷真題」 (+54 題)**：
   - 109 年與 110 年因應 COVID-19 疫情，教育部心測中心特別命題了「備用/補考卷」。我們的原始檔案庫（`D:\Kid's Vault\60_會考歷屆試題\`）完整收錄了這些官方真題並對位入庫，提供了額外 **+54 題** 寶貴會考題目。
2. **數學科「非選擇題子題獨立拆解 (Sub-questions)」 (+26 題)**：
   - 官方常態統計將非選題算作 2 題/年。我們的解析引擎將非選第(1)小題與第(2)小題（如計算與證明）拆解為獨立微觀卡片，13 個年度累積貢獻了額外 **+26 題** 的精細子題。
3. **英語科「聽力與閱讀獨立題號編碼」 (+24 題)**：
