### 🚨 一、 驗收反饋：3 大核心教學 Bug 與修正要求

#### 1. 【最嚴重 Bug】今日答對晉級之題目，依然重複出現在畫面上讓學生重答
- **問題現象**：當學生在 Web 端填寫答案並點擊晉級後，雖然資料庫將 `box_level` 提升，但頁面重新整理或 API 重新載入時，**該張已晉級的題目仍然顯示在今日清單下方**，強迫學生再答一次。
- **修正指示**：
  - `GET /api/tasks` 端點**必須加入過濾條件**：`WHERE status != 'mastered'`（只抓取今日**尚未完成**的防禦任務）。
  - 當學生判定答對後，前端該張閃卡應播放滑出淡出動畫並**立刻從清單中移除**，右上角「已成功晉級」數字自動 +1！

#### 2. 【核心教學缺陷】閃卡答題目前由學生自評對錯，應改為由 AI 自動判定
- **問題現象**：目前的 Web 閃卡是由學生自己看完答案後點擊「答對晉級 ➔」或「卡關降級 ↩」。這容易讓孩子產生「對自己寬容」或無法精準判斷文字/數字答案是否正確。
- **修正指示**：
  - **徹底移除網頁上的學生自評按鈕**。
  - 新增 `POST /api/verify` 判題端點：學生在實體阻力區輸入答案點擊「提交驗證」後，**由 AI / 後端比對邏輯自動判定答案對錯**：
    - 判定正確 ➔ 自動顯示 `✅ 答對了！` ➔ 自動執行晉級 ➔ 閃卡滑出消失。
    - 判定不精準 ➔ 自動顯示 `❌ 還不夠精準喔！` ➔ 顯示解析 ➔ 自動執行降級。

#### 3. 【防護漏洞】缺少學期章節與超綱題目自動過濾機制
- **問題現象**：非當前學期/單元的題目（例如國二下的「一元二次方程式」）會無差別浮現給剛上國二上的孩子，造成認知挫折。
- **修正指示**：
  - 任務查詢 API 應支援學期/章節過濾標籤（如 `grade=8_up`）與 `scope_disputed != 1` 條件，確保非當前學期與標記爭議的超綱題預設絕不出現在孩子眼前。
